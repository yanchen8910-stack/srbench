    echo "========================================"
    docker build -t srbench/${SUBNAME} -f alg-Dockerfile --build-arg ALGORITHM=${SUBNAME} . 2>&1 | tail -5
    if [ $? -ne 0 ]; then
        echo "FAILED: $SUBNAME"
    fi
done

TF 1.x is not available for Python 3.9+. The only option is to use tensorflow.compat.v1 which is available in TF2. The tensorflow.contrib module is the hardest part — it was completely removed and has no direct replacement.
This is a fundamental incompatibility. udsr is a TF1-only codebase and cannot run on modern TF without a major rewrite.
The practical options are:

Skip udsr — it's not maintainable without TF1
Use an old Python 3.6 + TF 1.14 image — but these aren't available on conda-forge for modern Linux

My recommendation: skip udsr for now and document it as incompatible with modern TensorFlow. Move on and do a final summary of all working algorithms.
