TF 1.x is not available for Python 3.9+. The only option is to use tensorflow.compat.v1 which is available in TF2. The tensorflow.contrib module is the hardest part — it was completely removed and has no direct replacement.
This is a fundamental incompatibility. udsr is a TF1-only codebase and cannot run on modern TF without a major rewrite.
The practical options are:

Skip udsr — it's not maintainable without TF1
Use an old Python 3.6 + TF 1.14 image — but these aren't available on conda-forge for modern Linux

My recommendation: skip udsr for now and document it as incompatible with modern TensorFlow. Move on and do a final summary of all working algorithms.

Add --no_docker flag — it runs commands directly without containers. You just need to create the method folder:
bashmkdir -p experiment/methods/my_alg
Create experiment/methods/my_alg/__init__.py (empty), experiment/methods/my_alg/_params.py (optional tuning params), and experiment/methods/my_alg/regressor.py with this structure:
pythonfrom sklearn.base import BaseEstimator, RegressorMixin

est = MyAlgorithm()  # your estimator

def model(est):
    return str(est)  # symbolic expression string

def complexity(est):
    return len(str(est))  # model size metric
Then run:
bashcd /mnt/SSD/PhD/srbench/experiment
python3 analyze.py ~/pmlb/datasets/192_vineyard/192_vineyard.tsv.gz \
    --no_docker --local -ml my_alg -n_jobs 1 -fit_time_limit 3600
The --no_docker flag bypasses containers entirely and runs optimize_model.py directly in your local Python environment, so your algorithm just needs to be importable from experiment/methods/my_alg/regressor.py.
